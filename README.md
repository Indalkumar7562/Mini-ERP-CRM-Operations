# Mini ERP + CRM Operations Portal

A full-stack ERP and CRM application for managing customers, products, challans, inventory, stock movements and users.

## 🚀 Features

- User authentication
- JWT-based authorization
- Role-based access control
- Admin dashboard
- Customer management
- Product management
- Challan management
- Stock management
- Stock movement tracking
- PostgreSQL database
- Prisma ORM
- REST API
- React frontend

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS tailwind

### Backend
- Node.js
- Express.js
- TypeScript
- Prisma ORM
- JWT
- CORS

### Database
- PostgreSQL
